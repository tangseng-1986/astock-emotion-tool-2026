# A股市场情绪强弱分析工具 v6

本地运行的情绪强弱 + 弱转强信号工具，支持**盘中实时监测**与**盘后复盘**双模式，内置**趋势分级**、**扩大周期回测**、**参数敏感性分析**、**自动调参闭环**与**图表点击下钻**。可打包为 Windows EXE，数据全部本地存储，仅行情获取需联网。

数据源：akshare（东方财富）+ 腾讯实时行情 + 同花顺涨停原因。

> **GitHub 仓库说明**：仓库保存全部源码、文档、看板与首次启动数据。Windows EXE 成品及图标（二进制文件）单独放在 `A股情绪监测_EXE_v1.0.zip` 中；下载后解压，把 `assets` 文件夹放回源码目录即可用 `python build_exe.py` 重新打包。

## 一、桌面应用（推荐，EXE 或源码启动）

```bash
python desktop_app.py        # 源码启动（系统 Python 3.10，需 tkinter）
```

打包后双击 `dist/A股情绪监测/A股情绪监测.exe` 即可。五个标签页：

| 标签页 | 功能 |
|---|---|
| **盘中监测** | 启动后定时刷新腾讯实时行情（默认45秒），扫描自动/手动自选池+最近观察池；弱转强封板(涨停)/A杀(跌停)即时**弹窗+声音**提醒，按封板状态与涨幅给出"最优股"排名；实时价同步写入自选池跟踪记录 |
| **自选池管理** | 按代码手动加入自动/手动池（默认手动池）；表格展示入池后累计收益、区间最高/回撤与 T+5/T+10/T+20；选中即可**手动剔除**，剔除后停止跟踪并进入归档表；归档表可选中**彻底删除归档记录** |
| **盘后复盘** | 一键运行「收盘统计 → 观察池 → 回测(T+5/10/20) → 自动调参 → 自选池跟踪更新 → 生成HTML看板」，输出直接显示在窗口，可一键打开看板 |
| **参数设置** | 可视化调整五因子权重、可买等级、持有周期、连续大跌阈值、趋势斜率、刷新间隔、提醒开关、回测天数等，保存即生效（写 `data/user_settings.json`） |
| **运行日志** | 记录监测/复盘/信号事件 |

**看板第五项实时同步**：桌面应用运行时，第五项「自选池（自动/手动）·入池后持续跟踪」每 15 秒从本地控制服务拉取最新 `state.json` 重绘（加池/剔除后立即同步），不再停留在复盘生成那一刻；桌面应用未启动则显示生成时快照。其余章节是固定复盘快照，按标注日期保持不变。自动池条目若按旧规则纳入，会标注「旧规则入池」并继续跟踪，不会因自动调参自动剔除。

**首次启动不会"标的 0 只"**：EXE 内置 `seed_data/` 初始快照，首次运行时自动复制到 EXE 同级 `data/`（已有数据绝不覆盖），因此打开即可扫描上一次收盘生成的观察池；之后每次「盘后复盘」完成会自动刷新监测标的。状态栏同时显示**标的数**（自选池+观察池）与**显示数**（实时行情匹配成功的行数），便于区分"无标的"和"行情未匹配"。

**看板直达按钮**：看板顶部「工具控制」栏有四个按钮（参数设置窗口 / 启动盘中监测 / 盘后复盘+调参 / 自选池管理），点击通过本地服务 `127.0.0.1:18765` 直达桌面应用对应功能（需桌面应用正在运行；端口被占用时自动顺延并写入 `data/control_port.json`，看板自动读取）。第三项观察池每行「＋加自选」写入**手动自选池**，第五项双池表的「剔除」按钮停止跟踪并归档；对应接口为 `/api/watchlist/add|remove|list`，看板实时片段为 `/api/watchlist/panel`；监测标的数可用 `/api/monitor/status` 查询、`/api/monitor/reload` 强制刷新。

**系统托盘（关闭窗口不退出）**：点击窗口右上角 ✕ 或最小化，窗口会**收进系统托盘**，盘中监测、提醒、控制服务继续在后台运行。

| 托盘操作 | 效果 |
|---|---|
| 左键单击图标 | 打开/恢复主界面 |
| 右键 → 打开主界面 | 恢复窗口 |
| 右键 → 启动 / 停止盘中监测 | 控制后台监测 |
| 右键 → 盘后复盘（含回测+调参） | 后台一键复盘，完成用气泡提示（不弹模态框） |
| 右键 → 自选池管理 | 打开双池管理界面 |
| 右键 → **退出程序** | 真正结束进程（停监测 → 删托盘图标 → 关闭窗口） |

托盘为零第三方依赖的纯 Win32 实现（`tray_win.py`），与「可转债提醒」工具同一机制但窗口类与图标独立，两者可同时运行互不干扰。也可用本地接口 `/api/hide`、`/api/show`、`/api/quit` 控制。

## 二、命令行（main.py）

```bat
cd /d D:\workbuddy\2026-11-19-09-43-20\astock_sentiment
```

## 三、时序口径（核心）

```
【收盘复盘（15:10 后运行）】报告 = T 日收盘统计，供 T+1 观察
主池(前瞻) = T 日收盘涨停+跌停（剔除ST） -> 趋势过滤+破位过滤 -> 明日观察池（供 T+1）
回顾池     = T-1 收盘构建的观察池 + T 日实际表现（第六项跟踪表）
弱转强     = T-1 跌停 且 T 日反手涨停 → 按【洗盘前趋势】分 A/B/C/D 级
A杀        = T-1 涨停 且 T 日跌停       → 情绪转弱风险提示，不纳入自选池

【盘中实时（9:30-15:00 运行）】
待选池 = T-1 涨停+跌停；观察池 = 趋势过滤后叠加 T 日盘中实时状态
```

关键设计：信号在**全部待选池**上判定（弱转强本就是下跌后反转，先按趋势过滤会漏真信号），但**以趋势为主分级**——用"跌停洗盘之前"的趋势判断信号质量。收盘报告双池结构：第三项"明日观察池"与第六项"观察池跟踪"各司其职。

## 四、v6 三项关键改进

### 1. 连续大跌（破位）剔除增强
原规则只认"连续 N 日大跌"，漏掉了两类破位形态：
- **"跌停→反弹→再跌停"**（如阳光乳业：5日内两次 -10%、累计 -9.58%）→ 新增窗口累计跌幅判定；
- **"18日跌停、19日又跌停"**（如凯撒文化）盘后复盘时行情源K线尚未更新到当日，磁盘缓存把"只到T-1"的K线永久存下来，导致连续跌停只算了1天。

现规则（三层保险）：

> **连续 N 日大跌** OR **窗口内大跌次数≥2 且累计跌幅≤-8%** OR **涨跌停池权威字段「连续跌停」≥N** → 剔除观察池

同时修复数据层：
- `daily_kline()` 增加**缓存新鲜度校验**——缓存最后一根日期早于观察日时强制重拉一次（同进程只刷一次），杜绝滞后K线被永久复用；
- `classify_trend(kline, append_pct)` 支持把**涨跌停池当日真实涨跌幅**补进价格序列，即使行情源延迟也能正确算出连续跌停天数/窗口累计/趋势。

阈值（单日大跌%、窗口天数/次数、累计跌幅%）均可在设置窗口调整。破位股在待选池表逐只标注剔除原因（如"连续2日跌停(涨跌停池)"），评分对短期动能因子打 5 折。

### 2. 回测扩大 + 参数敏感性自动应用（闭环）
- **回测周期**：90 → **约250交易日（1年）**，股票宇宙上限 380 只，A级高位震荡样本从 1 → 8，各分级样本更充足。
- **主线周期切到 T+20（约1个月中线）**，不再以超短线 T+1/T+5 为主。
- **自动调参引擎** `auto_tune.py`：把回测敏感性结论转化为实际参数——
  - 分级可买等级：按主周期"期望值=收益×胜率×置信度"排序，**样本不足(<15)的等级不纳入**（避免小样本误导）；本期回测 C级(T+20 收益22.6%/胜80%)、D级(9.9%/87.5%)纳入，B级(-8.4%/34.8%)剔除，A级样本不足暂不纳入。
  - 评分门槛：门槛收益极差 <2% 判为"不敏感"则取消门槛过滤（避免误杀信号），否则选最优门槛。
  - 权重方案：选主周期期望最高的方案，逐项平滑（EMA）避免跳变。
  - 破位过滤：**用户风控要求，强制保留**，不因回测波动自动放宽。
  - 情绪分位：低情绪样本充足且高情绪更优时才启用过滤。
- 结果写入 `data/tuned_params.json`（主程序自动加载）与 `data/tune_history.json`（效果跟踪），看板新增「自动调参面板」展示决策依据与分级后验。**回测时按周自动重算**，无需手动。

### 3. 盘中监测 + 盘后复盘双模式
见「一、桌面应用」。盘中即时提醒弱转强/A杀，盘后自动复盘总结+调参。

## 五、弱转强趋势分级（可自动调参覆盖）

| 等级 | 洗盘前趋势 | 信号类型 | 默认处理 | v6本期回测(T+20) |
|---|---|---|---|---|
| A | 高位震荡 | 高位平台反包型 | 观察（样本不足） | 收益6.8%/胜75%（8样本，不足） |
| B | 上升趋势 | 上升趋势洗盘型 | 观察（本期回测偏弱） | 收益-8.4%/胜34.8%（42样本） |
| C | 震荡偏弱 | 弱势反抽/中线修复型 | 中线关注 | 收益22.6%/胜80%（27样本） |
| D | 下跌趋势 | 下跌反转型 | 中线关注 | 收益9.9%/胜87.5%（17样本） |

> 实际可买等级以 `data/tuned_params.json` 为准（看板「自动调参面板」可见），并随每周回测自动更新；用户可在设置窗口手动锁定。分级依据回测相对比较，非投资建议。

## 六、功能与口径

| 模块 | 逻辑 |
|---|---|
| 待选池 | 涨停+跌停剔除ST，按涨停/跌停分开统计纳入率与破位剔除数；数据源重复索引/同码多行会在清洗和候选构建两层去重（同码保留连板数更高、方向与类型一致的记录） |
| 破位大跌剔除 | 连续N日大跌 或 窗口多次大跌且累计跌幅超阈值，逐只标注原因 |
| 趋势标签 | 60 日前复权 K 线：上升趋势=斜率>4%且价≥MA60且MA20≥0.98MA60；高位震荡=价≥0.85×60日高且≥0.93MA60且回撤≤18%；下跌趋势=斜率≤−5%且价<0.97MA60且非高位；其余为震荡偏弱（高位区优先判 A/B） |
| 弱转强 ABCD | 按**跌停洗盘前趋势**分级：A=高位平台反包、B=上升趋势洗盘、C=弱势反抽/中线修复、D=下跌反转；等级≠可买，可买等级由自动调参/设置窗口动态决定 |
| 个股评分 | 五因子：趋势/高位/封板质量/题材/短期动能（设置窗口或 `--weights` 调整） |
| 行情口径一致性 | 状态/涨跌幅/现价同源：收盘优先真实涨跌停池，其次当日快照，最后K线且严格校验日期==观察日（杜绝"跌停却+10%"） |
| 情绪温度计 | 涨停/跌停家数 + 炸板率 + 最高连板 + 打板溢价 |
| 回测校验 | 约1年回放，T+5/T+10/T+20 收益胜率 + 五类敏感性 |
| 日期标注 | 表头与说明全部用真实交易日（11-18、11-19） |
| 自动自选池 | 弱转强信号达到当前可买等级时自动纳入；旧版扁平 `watchlist` 会自动迁移到 `auto` 池 |
| 手动自选池 | 看板第三项「＋加自选」或桌面「自选池管理」录入；同一只股票只在一个池，加入另一池视为迁移且保留跟踪历史 |
| 持续跟踪 | 从入池日起按前复权收盘价统计持有交易日、累计收益、区间最高收益/最大回撤与 T+5/T+10/T+20；盘中用腾讯实时快照刷新最新价/状态；点击看板代码可看逐日快照 |
| 手动剔除与归档 | 看板第五项或桌面界面均可剔除；剔除后停止更新，终态统计写入 `watchlist_archive`，历史快照保留。归档表「删除归档」会不可恢复地清除该归档及其跟踪数据 |
| 实时状态不丢失 | 收盘复盘若遇K线缓存滞后，用腾讯实时快照补齐当日K线，避免手动池个股显示「—」或状态缺失；历史日期回填不会拿今天行情覆盖 |

状态文件 `data/state.json` 结构：`watchlist: {auto, manual}`、`tracking`（逐股统计+快照）、`watchlist_archive`（剔除终态）。所有写入在本地控制服务/监测线程间加锁，避免并发覆盖。

## 七、打包为 EXE

用系统 Python 3.10（含 tkinter + pyinstaller）：

```bat
cd /d D:\workbuddy\2026-11-19-09-43-20\astock_sentiment
python build_exe.py
```

**务必用 `build_exe.py` 打包**：PyInstaller 重建目录时会清空 `dist/A股情绪监测/`，该脚本会先备份 `data/`、`reports/`，构建后自动恢复，避免每次打包都把用户的自选池、跟踪记录和看板清掉。不要直接跑 `python -m PyInstaller build.spec --noconfirm` 覆盖，也不要加 `--clean`（会触发环境批量删除保护）。

产物在 `dist/A股情绪监测/`，整个目录拷到任意 Windows 电脑即可运行（无需 Python）。数据（data/、reports/）自动落地在 EXE 同级目录。**首次运行需联网**获取行情；涨停原因同花顺接口为非一手来源，标注"需核实"。

EXE 与托盘图标为本工具**专属设计**：`assets/app.ico`（深蓝底 + 红涨绿跌K线 + 金色上升箭头 + 实时监测信号点），由 `make_icon.py` 用 Pillow 离线生成（含 16~256 共 7 档尺寸），与「可转债提醒」工具图标不同。改设计后重跑 `python make_icon.py` 再打包即可。
